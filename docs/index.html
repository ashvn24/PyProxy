Accelerate Your Python Network Requests

PyProxy is a production-grade, event-driven reverse proxy & load balancer built entirely in Python on asyncio.

# Use as a Python Library (No config.yaml needed)
from pyproxy import Proxy
proxy = Proxy(port=8080)
proxy.add_route("/api", targets=[("127.0.0.1", 8001)])
proxy.run()

Asyncio & Connection Pools

Non-blocking TCP socket server with persistent upstream connection pooling and socket option tuning (TCP_NODELAY).

5 Load Balancing Algorithms

Round Robin, Smooth Weighted RR, Least Connections, IP Hash, and Cookie-based Sticky Sessions.

Circuit Breaker & Probes

Active TCP probing and passive failure detection with CLOSED / OPEN / HALF_OPEN state recovery.

HTTPS & TLS Termination

TLS 1.2/1.3 enforcement, SNI certificate matching, and Mutual TLS (mTLS) client verification.

WebSocket Tunneling

RFC 6455 101 Switching Protocols handshakes and bidirectional async streaming frame tunnels.

Caching & Compression

In-memory caching with ETag generation, 304 conditional responses, and gzip payload compression.

v0.1.3 Released

Recent Enhancements

  • Pure Python Library API: Run Proxy(port=8080) directly in Python with zero YAML required.
  • In-Memory TTL Caching: Sub-millisecond response caching with automatic POST/PUT cache invalidation.
  • Token Bucket Rate Limiter: Protect backends per IP with configurable burst capacity.
  • Windows Proactor Stability: Silent socket disconnect & proactor exception handling.

FastAPI Centralized Gateway

Mount PyProxy as an ASGI middleware or router directly inside FastAPI / Starlette to act as an all-in-one centralized microservices gateway service. 

from fastapi import FastAPI
from pyproxy.asgi import PyProxyGateway

app = FastAPI(title="Central Gateway")
app.add_middleware(PyProxyGateway, routes=...)
server:
  bind_host: "0.0.0.0"
  bind_port: 8080

routes:
  - path: "/api"
    upstream:
      targets:
        - host: "127.0.0.1"
          port: 3000

logging:
  level: "info"
  format: "json"
