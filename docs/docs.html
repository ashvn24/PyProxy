PyProxy Documentation v0.1.3

PyProxy (published as python-pyproxy on PyPI) is a high-performance reverse proxy and load balancer built entirely from scratch in Python on asyncio.

Terminalpip
pip install python-pyproxy

Command Line Interface

PyProxy includes a full command-line suite for managing your proxy daemon.

CLI Commandsbash
# Validate a configuration file pyproxy validate config.yaml # Start the proxy server pyproxy start config.yaml # Print version pyproxy version

1. Asyncio TCP Server Engine

High-performance non-blocking socket listener with TCP_NODELAY and graceful connection draining.

Server Configuration Example

Controls TCP socket bindings, timeouts, maximum connection limits, and graceful shutdown thresholds.

config.yamlYAML
server: bind_host: "0.0.0.0" bind_port: 8080 backlog: 1024 keepalive_timeout: 75.0 read_timeout: 30.0 write_timeout: 30.0 max_connections: 5000 shutdown_timeout: 30.0

2. HTTP Request Parser

Streamed parsing of HTTP/1.1 methods, headers, cookies, query strings, and chunked request bodies.

Python APIPython
from pyproxy.protocol import HTTPParser # Parse incoming request stream from Connection request = await HTTPParser.parse_request(connection) print(request.method, request.path, request.headers.get("Host"))

3. Response Builder Engine

Serializes status codes, headers, and streams chunked or byte-buffered responses with Range support.

4. Routing Engine

Supports Longest-Prefix, Exact, Regular Expression, Host Wildcard, and Method-based route matching.

config.yaml — Routing RulesYAML
routes: - path: "/api/v1" strip_prefix: true methods: ["GET", "POST"] upstream: targets: - host: "127.0.0.1" port: 3000 - path: "/" upstream: targets: - host: "127.0.0.1" port: 8000

5. Reverse Proxy Engine

Header manipulation (X-Forwarded-For, X-Real-IP, Forwarded RFC 7239), host rewriting, and response streaming.

6. Upstream Connection Pool

Maintains reusable persistent idle connection queues to backend targets with automatic retry policies.

7. Load Balancer

5 Algorithms: Round Robin, Smooth Weighted Round Robin, Least Connections, IP Hash, and Sticky Sessions.

8. Health Probes & Circuit Breaker

Active TCP probes and passive failure tracking with CLOSED, OPEN, and HALF_OPEN circuit state transitions.

9. HTTPS & TLS Termination

TLS 1.2/1.3 enforcement, certificate chain loading, SNI matching, and Mutual TLS (mTLS) client verification.

TLS ConfigurationYAML
tls: enabled: true cert_path: "/etc/ssl/certs/server.crt" key_path: "/etc/ssl/private/server.key" min_version: "1.3" ca_path: "/etc/ssl/certs/client_ca.crt" # Enables mTLS

10. WebSocket Tunneling

RFC 6455 101 Switching Protocols handshakes and bidirectional async streaming frame tunnels.

11. Middleware Pipeline

Ordered before-request and after-response hooks for custom transformations and short-circuiting.

12. Caching System

In-memory TTL cache, ETag generation, Cache-Control parsing, 304 Not Modified responses, and automatic cache invalidation on mutating requests (POST, PUT, DELETE).

Cache ConfigurationYAML
cache: enabled: true max_size: 1000 ttl: 60.0 # In-memory TTL in seconds

13. Compression Engine

gzip Content-Encoding negotiation and payload compression with Vary header injection.

14. Authentication Middleware

HTTP Basic Auth, API Key header/query validation, and JWT token hooks.

15. Security & Rate Limiting

Token bucket rate limiting per client IP (HTTP 429), CIDR allowlist/denylist filtering, and CORS preflight handling.

Security ConfigurationYAML
security: rate_limiter: enabled: true rate: 10.0 # 10 requests per second burst: 15 # Token bucket max capacity cors: enabled: true allow_origins: ["*"]
