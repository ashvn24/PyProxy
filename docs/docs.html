PyProxy Documentation v0.1.3

PyProxy (published as python-pyproxy on PyPI) is a high-performance reverse proxy and load balancer built entirely from scratch in Python on asyncio.

Terminal Installationpip
pip install python-pyproxy

Command Line Interface (CLI)

PyProxy includes a command-line interface for validating configurations and running reverse proxy daemons.

CLI SuiteCLI
# Validate a configuration file pyproxy validate config.yaml # Start the reverse proxy daemon pyproxy start config.yaml # Display PyProxy version pyproxy version

1. Asyncio TCP Server Engine

Non-blocking TCP socket server with persistent connection handling, TCP_NODELAY, and configurable timeouts.

Option A: YAML Configurationconfig.yaml
server: bind_host: "0.0.0.0" bind_port: 8080 max_connections: 5000 keepalive_timeout: 75.0 read_timeout: 30.0
Option B: Python Library APIPython
from pyproxy import Proxy proxy = Proxy( host="0.0.0.0", port=8080, config={ "server": { "max_connections": 5000, "keepalive_timeout": 75.0 } } ) proxy.run()
Option C: CLI Daemon CommandCLI
pyproxy start config.yaml --host 0.0.0.0 --port 8080

4. Routing Engine

Supports prefix matching, path stripping, HTTP method filtering, and dynamic route registration.

Option A: YAML Configurationconfig.yaml
routes: - path: "/api/v1" strip_prefix: true methods: ["GET", "POST"] upstream: targets: - host: "127.0.0.1" port: 8001
Option B: Python Library APIPython
from pyproxy import Proxy proxy = Proxy(port=8080) proxy.add_route( path="/api/v1", targets=[("127.0.0.1", 8001)], methods=["GET", "POST"], strip_prefix=True ) proxy.run()
Option C: CLI VerificationCLI
pyproxy validate config.yaml

7. Load Balancer

5 Algorithms: Round Robin, Smooth Weighted Round Robin, Least Connections, IP Hash, and Sticky Sessions.

Option A: YAML Configurationconfig.yaml
routes: - path: "/service" upstream: algorithm: "least_connections" targets: - host: "10.0.0.1" port: 8001 weight: 3 - host: "10.0.0.2" port: 8002 weight: 1
Option B: Python Library APIPython
from pyproxy import Proxy proxy = Proxy( port=8080, config={ "routes": [ { "path": "/service", "upstream": { "algorithm": "least_connections", "targets": [ {"host": "10.0.0.1", "port": 8001, "weight": 3}, {"host": "10.0.0.2", "port": 8002, "weight": 1} ] } } ] } ) proxy.run()

9. HTTPS & TLS Termination

TLS 1.2/1.3 encryption, SNI matching, certificate chain loading, and Mutual TLS (mTLS) client verification.

Option A: YAML Configurationconfig.yaml
tls: enabled: true cert_path: "/etc/ssl/certs/server.crt" key_path: "/etc/ssl/private/server.key" min_version: "1.3" ca_path: "/etc/ssl/certs/ca.crt" # Optional mTLS
Option B: Python Library APIPython
from pyproxy import Proxy proxy = Proxy( port=8443, config={ "tls": { "enabled": True, "cert_path": "/etc/ssl/certs/server.crt", "key_path": "/etc/ssl/private/server.key", "min_version": "1.3" } } ) proxy.run()

12. Caching System

In-memory TTL cache, ETag generation, Cache-Control parsing, 304 responses, and auto-invalidation on POST/PUT/DELETE.

Option A: YAML Configurationconfig.yaml
cache: enabled: true max_size: 1000 ttl: 60.0 # In-memory TTL in seconds
Option B: Python Library APIPython
from pyproxy import Proxy proxy = Proxy( port=8080, config={ "cache": { "enabled": True, "ttl": 60.0 } } ) proxy.add_route("/api", targets=[("127.0.0.1", 8001)]) proxy.run()

15. Security & Rate Limiting

Token bucket rate limiting per client IP (HTTP 429), CIDR allowlist/denylist filtering, and CORS preflight headers.

Option A: YAML Configurationconfig.yaml
security: rate_limiter: enabled: true rate: 10.0 # Tokens refilled per second burst: 15 # Max token bucket capacity cors: enabled: true allow_origins: ["*"]
Option B: Python Library APIPython
from pyproxy import Proxy proxy = Proxy( port=8080, config={ "security": { "rate_limiter": { "enabled": True, "rate": 10.0, "burst": 15 }, "cors": { "enabled": True, "allow_origins": ["*"] } } } ) proxy.run()
