PyProxy Documentation v0.1.3

PyProxy (published as python-pyproxy on PyPI) is a high-performance reverse proxy and load balancer built entirely from scratch in Python on asyncio. 

pip install python-pyproxy

Command Line Interface (CLI)

PyProxy includes a command-line interface for validating configurations and running reverse proxy daemons.

# Validate a configuration file
pyproxy validate config.yaml

# Start the reverse proxy daemon
pyproxy start config.yaml

# Display PyProxy version
pyproxy version

1. Asyncio TCP Server Engine

Non-blocking TCP socket server with persistent connection handling, TCP_NODELAY, and configurable timeouts.

server:
  bind_host: "0.0.0.0"
  bind_port: 8080
  max_connections: 5000
  keepalive_timeout: 75.0
  read_timeout: 30.0
from pyproxy import Proxy

proxy = Proxy(
    host="0.0.0.0",
    port=8080,
    config={
        "server": {
            "max_connections": 5000,
            "keepalive_timeout": 75.0
        }
    }
)
proxy.run()
pyproxy start config.yaml --host 0.0.0.0 --port 8080

4. Routing Engine

Supports prefix matching, path stripping, HTTP method filtering, and dynamic route registration.

routes:
  - path: "/api/v1"
    strip_prefix: true
    methods: ["GET", "POST"]
    upstream:
      targets:
        - host: "127.0.0.1"
          port: 8001
from pyproxy import Proxy

proxy = Proxy(port=8080)

# Dynamically register routes programmatically
proxy.add_route(
    path="/api/v1",
    targets=[("127.0.0.1", 8001)],
    methods=["GET", "POST"],
    strip_prefix=True
)
proxy.run()
pyproxy validate config.yaml

7. Load Balancer

5 Algorithms: Round Robin, Smooth Weighted Round Robin, Least Connections, IP Hash, and Sticky Sessions.

routes:
  - path: "/service"
    upstream:
      algorithm: "least_connections"
      targets:
        - host: "10.0.0.1"
          port: 8001
          weight: 3
        - host: "10.0.0.2"
          port: 8002
          weight: 1
from pyproxy import Proxy

proxy = Proxy(
    port=8080,
    config={
        "routes": [
            {
                "path": "/service",
                "upstream": {
                    "algorithm": "least_connections",
                    "targets": [
                        {"host": "10.0.0.1", "port": 8001, "weight": 3},
                        {"host": "10.0.0.2", "port": 8002, "weight": 1}
                    ]
                }
            }
        ]
    }
)
proxy.run()
pyproxy start config.yaml

9. HTTPS & TLS Termination

TLS 1.2/1.3 encryption, SNI matching, certificate chain loading, and Mutual TLS (mTLS) client verification.

tls:
  enabled: true
  cert_path: "/etc/ssl/certs/server.crt"
  key_path: "/etc/ssl/private/server.key"
  min_version: "1.3"
  ca_path: "/etc/ssl/certs/ca.crt" # Enables mTLS
from pyproxy import Proxy

proxy = Proxy(
    port=8443,
    config={
        "tls": {
            "enabled": True,
            "cert_path": "/etc/ssl/certs/server.crt",
            "key_path": "/etc/ssl/private/server.key",
            "min_version": "1.3"
        }
    }
)
proxy.run()
pyproxy start config.yaml

12. Caching System

In-memory TTL cache, ETag generation, Cache-Control parsing, 304 responses, and auto-invalidation on POST/PUT/DELETE.

cache:
  enabled: true
  max_size: 1000
  ttl: 60.0 # In-memory TTL in seconds
from pyproxy import Proxy

proxy = Proxy(
    port=8080,
    config={
        "cache": {
            "enabled": True,
            "ttl": 60.0
        }
    }
)
proxy.add_route("/api", targets=[("127.0.0.1", 8001)])
proxy.run()
pyproxy start config.yaml

15. Security & Rate Limiting

Token bucket rate limiting per client IP (HTTP 429), CIDR allowlist/denylist filtering, and CORS preflight headers.

security:
  rate_limiter:
    enabled: true
    rate: 10.0  # Tokens refilled per second
    burst: 15   # Max token bucket capacity
  cors:
    enabled: true
    allow_origins: ["*"]
from pyproxy import Proxy

proxy = Proxy(
    port=8080,
    config={
        "security": {
            "rate_limiter": {
                "enabled": True,
                "rate": 10.0,
                "burst": 15
            },
            "cors": {
                "enabled": True,
                "allow_origins": ["*"]
            }
        }
    }
)
proxy.run()
pyproxy start config.yaml

16. Roadmap & Centralized FastAPI Gateway

Overview of newly added v0.1.3 capabilities and upcoming support for FastAPI acting as a centralized reverse proxy service.

v0.1.3 Highlights (Available Now)

  • Programmatic Python Library API: Run Proxy(port=8080), pass raw python dict configs, and register dynamic routes with proxy.add_route("/path", targets=[...]).
  • In-Memory Response Caching: Sub-millisecond cache delivery with automatic POST/PUT cache invalidation.
  • Token Bucket Rate Limiting: Sliding-window per-IP rate limiting (HTTP 429).
  • Windows Socket & Proactor Exception Suppression: Clean socket shutdown handling.

Coming Soon: Centralized FastAPI Service Integration

PyProxy will offer a native ASGI middleware layer so it can be mounted directly into any FastAPI / Starlette application as an all-in-one centralized API Gateway service: 

from fastapi import FastAPI
from pyproxy.asgi import PyProxyGateway

app = FastAPI(title="Central Microservices Gateway")

# Mount PyProxy directly into FastAPI as a centralized service
app.add_middleware(
    PyProxyGateway,
    routes=[
        {"path": "/users", "target": "http://user-service:8001"},
        {"path": "/orders", "target": "http://order-service:8002"},
    ]
)

@app.get("/health")
def gateway_health():
    return {"status": "healthy", "gateway": "PyProxy Centralized"}
